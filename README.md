# 🌊 PastelWave Landing Page

Una página de aterrizaje moderna y liviana desplegada en un contenedor Docker con Nginx.

## 🚀 Cómo ejecutar localmente con Docker Compose

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/xandervegas/mi-landing-page.git](https://github.com/xandervegas/mi-landing-page.git)
   cd mi-landing-page
Levantar el contenedor:

Bash
docker compose up -d
Acceder a la aplicación:
Abre tu navegador en http://localhost:9595

📦 Imagen en Docker Hub
Puedes descargar directamente la imagen compilada desde Docker Hub:

Bash
docker pull soyalexj/mi-landing-page:demos_version1.0
🛠️ Tecnologías utilizadas
Frontend: HTML5, CSS3

Servidor Web: Nginx (Alpine)

Contenerización: Docker & Docker Compose
